# Contributing

Thanks for joining the workshop! Pull requests here follow a few simple rules.

1. **Fork first.** Work on your own fork, never on someone else's branch.
2. **One branch per change.** Name it `add-your-name` for your participant file.
3. **One file per person.** Add `participants/your-name.md` only. Don't edit other people's files.
4. **Use the template.** Copy `participants/_template.md` and keep its format so the wall can read it.
5. **Lowercase file names with dashes:** `participants/sarra-ben-ali.md`, not `Sarra Ben Ali.md`.
6. **Clear commit messages:** `docs: add sarra-ben-ali`.
7. **Be kind.** No offensive content. Pull requests that break these rules are closed with a comment.

The only exception is the **bonus challenge** in the README, where everyone edits the first line of `README.md` on purpose to practise resolving conflicts.
